# n8n Google Forms Email Automation

## Project Overview

This project demonstrates an automated workflow built with **n8n** that processes Google Form submissions, stores the responses in Google Sheets, and sends different email notifications through Gmail based on predefined conditions.

The workflow eliminates manual processing and showcases workflow automation, API integration, and cloud-based productivity tools.

---

## Workflow Diagram

![Workflow](screenshots/n8n-workflow.JPEG)
1. User submits a Google Form.
2. n8n detects the new submission.
3. Data is appended to a Google Sheet.
4. A Switch node evaluates the submitted data.
5. Gmail sends different email notifications depending on the conditions.
